# 端材専門フリマアプリ「はざいち」

## 📱 チーム役割分担（3人体制）
- **メンバーA（基盤・ホーム）**: 全体基盤、検索バー、カテゴリ選択、商品一覧カード、ボトムナビ
- **メンバーB（商品詳細）**: 画像スライダー、素材タグ、背景ストーリーカード、購入ボタン
- **メンバーC（出品画面）**: 写真アップロード枠、素材種別選択、各種フォーム、出品確認ボタン
